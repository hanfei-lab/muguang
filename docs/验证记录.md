# 暮光 0.2.1 图标修复验证

本次针对用户反馈的 macOS 10.15 应用程序图标异常，修复图标资源生成和元数据。日期：2026-10-17，构建环境：macOS 13.4 / Swift 5.8.1。

## 修复内容

原实现手工将 PNG 写入 ICNS，缺少传统 16/32 像素 RGB 与透明蒙版资源。本版改由系统 ImageIO ICNS 编码器生成，补齐 is32/s8mk、il32/l8mk、TOC 以及 Retina 等资源。绘制使用明确尺寸的 sRGB 位图，避免构建机器屏幕缩放影响像素大小。

CFBundleIconFile 明确指向新的 MuguangIcon-v021.icns 文件，应用与辅助组件版本均为 0.2.1，构建号 3。菜单栏图标和功能代码沿用 0.2.0，仅更新诊断版本文案。

## 本次验证通过

- 系统 ICNS 编码完成，图层目录与各图层长度一致。
- 16/32 像素传统 RGB 图层与透明蒙版存在，蒙版同时含透明及不透明像素。
- 系统 iconutil 能将成品解包为十张图标，普通与 Retina 资源尺寸均匹配名称。
- ImageIO 解码全部十个图像，均有可见图案、有效透明度，涵盖 16、32、64、128、256、512、1024 像素。
- 目视检查成品 1024 像素图标，沿用原日落图案。
- 主程序与辅助组件最低目标仍为 Intel macOS 10.15、arm64 macOS 11.0，两个 Info.plist 和四个架构切片已检查。
- 主应用及嵌入式登录组件的临时签名严格验证通过。
- 只读诊断输出 0.2.1。

0.2.0 已通过的计算、模拟显示器及登录支持测试，其对应功能代码本次未改动。

## 实际限制

当前会话无法访问桌面显示器，也没有 Catalina 测试系统。未复现用户设备上的具体外观，以上检查不等于在 macOS 10.15 的 Finder、Dock、启动台实测通过。图标缓存刷新和实际显示需要在用户设备确认。应用仍为临时签名，尚未开发者签名或 Apple 公证。

图标资源规范参考 Apple 的[高分辨率图标文档](https://developer.apple.com/library/archive/documentation/GraphicsAnimation/Conceptual/HighResolutionOSX/Optimizing/Optimizing.html)。
