# 暮光 0.2.2 · 锁屏恢复修复版

完成日期：2026-10-21。

## 修复内容

- 修复系统在解锁后再次恢复原色时，程序因设置未变而不再应用暖光的问题。
- 修复显示器唤醒时暂未就绪或写入失败后，相同设置不能自动重试的问题。
- 增加解锁/唤醒后的几次短暂重试，以及暖光生效期间约每 5 秒的实际色彩检查。系统调度可能推迟检查，不承诺固定恢复时限。
- 分开处理系统睡眠、屏幕睡眠和用户会话状态，保留原始校色数据，避免重复叠加暖光。
- 延迟重试始终使用最新设置，尊重暂停、关闭和白天定时状态。
- 保留 0.2.1 的图标修复与旧系统兼容目标。

## 安装

1. 先从菜单栏退出旧版暮光。
2. 用本包中的「暮光.app」替换「应用程序」中的旧版。
3. 打开新版，原有设置会保留。

建议在开启暖光后锁屏并解锁一次，再分别检查暂停和定时模式的表现。如仍出现色彩异常，请记录系统版本、内外接显示器，以及等待几秒后是否自行恢复。

## 系统与验证范围

Intel 最低编译目标仍为 macOS 10.15，Apple 芯片为 macOS 11。应用仍使用临时签名，尚未通过 Apple 开发者签名与公证。

新增 33 项模拟恢复回归测试已通过，原有计算、模拟显示器和登录支持测试亦通过。双架构编译、最低系统要求、图标及签名验证通过。

当前构建会话无法访问实际桌面显示器，因此尚未在真实 Mac（含 Catalina）上完成锁屏、解锁和显示器唤醒验证。详见「验证记录.md」。
