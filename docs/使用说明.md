# 暮光 0.2.2

轻量原生 macOS 菜单栏暖屏工具。Intel 版本最低编译目标为 macOS 10.15 Catalina，Apple 芯片版本为 macOS 11，包含两个架构。本版本不联网、不需要账号。10.15 实机验证尚未完成。

升级时先退出旧版暮光，再用新应用替换「应用程序」中的旧版。原有色温和定时设置保留。


## 0.2.2 锁屏恢复修复

本版修复锁屏/解锁及唤醒后暖光可能丢失的问题：恢复后短暂分阶段重试，并在暖光生效时约每 5 秒核对实际色彩。暂停、关闭或进入白天时，不会因重试而重新变暖。

系统调度和显示器就绪可能推迟恢复；真实 Mac 上的锁屏解锁效果仍需确认。原有图标修复及系统兼容目标保留。请先退出旧版，再替换应用。

## 开始使用

1. 把「暮光.app」拖入「应用程序」，然后双击打开。
2. 点击顶部菜单栏的太阳图标，打开右上角的开关。
3. 选择「手动调节」，拖动色温和亮度滑块；也可以点击柔和、暖光、烛光预设。
4. 要自动切换，选择「定时调节」。默认晚上 21:00 到次日 07:00，开始后与结束前分别用 30 分钟渐变，白天恢复原色。

「暂停 15 分钟」会暂时恢复原色，到时自动继续。「恢复原色」会关闭调节；退出应用也会恢复。右键菜单栏图标也可以执行这些操作。

先把应用放入「应用程序」，再勾选「登录时启动」。macOS 13 及以上如果显示待批准，到「系统设置 → 通用 → 登录项」允许暮光。macOS 10.15–12 使用内置登录辅助组件，这类登录项可能不会出现在「系统偏好设置」的登录项列表中，请在暮光内取消勾选来关闭它。旧系统上的实际启动流程仍待实测。

## 显示与兼容

- 色温范围 2700–6500K；6500K 且亮度 100% 保持原有色彩。
- 亮度为软件调暗，范围 30–100%，不调节显示器背光，也不承诺减少耗电或改变 PWM。
- 调节覆盖支持 gamma 表的在线显示器。镜像屏跟随主显示器，不提供逐屏参数。
- 初次开启时记录各显示器原有 gamma 表，暂停或退出时恢复；睡眠和用户切换时恢复，唤醒后重新应用。
- 应用异常退出时，独立恢复进程会尝试恢复系统 ColorSync 配置。此时恢复的是系统配置，可能与其他调色工具的临时设置不同。
- 使用时建议关闭 Night Shift、f.lux、Iris 等其他色温工具，避免互相覆盖。True Tone、HDR、参考模式、虚拟屏和部分外接显示器可能影响效果，需在实际设备上验证。
- 已读取的原始 gamma 表会保留到恢复原色。如果使用期间更换色彩配置，请先关闭暮光调节，更换配置后再开启。

## 系统提示与恢复

此构建采用本机临时签名，没有 Apple 开发者签名和公证。在其他 Mac 上打开时可能出现来源提示，可按 macOS 提示处理：旧系统可在「系统偏好设置 → 安全性与隐私」查看，新系统在「系统设置 → 隐私与安全性」查看。

如果屏幕色彩异常，先点「恢复原色」或退出暮光。必要时，在终端运行以下命令（路径按实际安装位置修改）：

```sh
"/Applications/暮光.app/Contents/MacOS/Muguang" --restore
```

运行中的暮光可能再次应用设置，因此先关闭调节或退出，再执行恢复。恢复命令会恢复所有显示器的系统 ColorSync 配置。

## 源码与构建

完整源码在 `Muguang-Source` 中，无第三方依赖。安装 Apple Command Line Tools 后，可以执行：

```sh
cd Muguang-Source
bash test.sh
bash build.sh
```

构建脚本会生成双架构应用，默认输出到源码文件夹的上一层。临时编译目录可以通过环境变量 `MUGUANG_BUILD_DIR` 指定。

只读诊断（不会修改屏幕）：

```sh
"/Applications/暮光.app/Contents/MacOS/Muguang" --diagnostics
```

界面与控件自检（不会修改屏幕或保存设置）：

```sh
"/Applications/暮光.app/Contents/MacOS/Muguang" --smoke-test
```
