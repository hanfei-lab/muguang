# 暮光 · Muguang

一个小巧的原生 Mac 菜单栏暖屏工具，让夜晚柔和一点。

**当前版本：0.2.2 锁屏恢复修复版。**

## 下载与安装

### [点击下载 Mac 安装包](https://github.com/hanfei-lab/muguang/raw/refs/heads/main/downloads/muguang-v0.2.2-macos.zip)

1. 解压下载的 ZIP，将「暮光.app」拖到「应用程序」。
2. 打开应用，点击顶部菜单栏的太阳图标。
3. 开启右上角开关，按喜好调整色温与亮度。

升级前先退出旧版，再替换应用，原有设置会保留。若 Finder 或启动台仍显示旧图标，可尝试重新登录系统。

[下载 0.2.2 源码包](downloads/muguang-v0.2.2-source.zip) · [校验值](downloads/SHA256SUMS.txt) · [完整使用说明](docs/使用说明.md)

## 能做什么

- 色温调节：2700–6500K，提供柔和、暖光、烛光三个预设。
- 软件调暗：画面亮度 30–100%。
- 手动与定时模式：默认 21:00 至次日 07:00，开始后和结束前各用 30 分钟渐变。
- 暂停 15 分钟，到时继续；也可随时恢复原色。
- 登录时启动、睡眠唤醒处理及异常退出恢复保护。
- 无账号、无联网请求、无遥测，无第三方运行依赖。

软件调暗不改变显示器背光；色温数值为近似换算，不承诺医疗或视力保护效果。

## 系统要求与已知限制

| 芯片 | 最低编译目标 |
| --- | --- |
| Intel | macOS 10.15 Catalina |
| Apple 芯片 | macOS 11 Big Sur |

这是早期试用版本。已通过兼容编译、图标与安装包检查；**尚未完成 macOS 10.15、Apple 芯片及实际显示器的完整实机验收**。HDR、参考模式和部分外接显示器可能不支持 gamma 调节。建议关闭其他色温工具，避免叠加。

应用采用临时签名，尚未通过 Apple 开发者签名与公证；首次打开可能出现来源提示。请阅读 [使用说明](docs/使用说明.md) 和 [验证记录](docs/验证记录.md)。

## 0.2.2 修复了什么

- 修复解锁或唤醒后色温恢复原色、相同设置不再应用的问题。
- 增加短暂分阶段重试，处理显示器尚未就绪和系统稍后再次重置色彩的情况。
- 暖光应生效时，约每 5 秒核对实际色彩；健康状态不重复写入。计时可能受系统调度影响。
- 延迟重试读取最新设置，尊重暂停、关闭和白天定时状态。
- 保留原始校色数据，避免临时断屏后叠加暖光。

新增 **33 项模拟恢复回归检查已通过**。真实 Mac 的锁屏/解锁、Catalina 和外接显示器表现仍需实测。

## 从源码构建

安装 Apple Command Line Tools 后，在仓库根目录运行：

```sh
bash test.sh
bash build.sh
```

脚本生成 Intel / Apple 芯片双架构应用，默认输出到仓库上一层。开发细节见 [开发说明](docs/开发说明.md)。
